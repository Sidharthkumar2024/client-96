# client-96

Billion Group — Commercial Real Estate Advisory & Capital Markets firm website.

A full front-end recreation of billiongroup.ca: high-contrast editorial serif design,
scroll-reveal animations, animated counters, word-by-word statement reveal, marquees,
testimonial carousel, FAQ accordion, contact form, and a fully responsive layout.

## Stack
- Static HTML / CSS / vanilla JavaScript (no build step)
- Google Fonts (Fraunces + Manrope)

## Structure
```
index.html        # all sections
css/styles.css    # design system, layout, animations, responsive
js/main.js        # reveals, counters, carousel, accordion, mobile menu
```

## Run locally
```bash
python3 -m http.server 8000
# open http://localhost:8000
```
